# Self Kasa Beklenmeyen Nesne Savcılığı

Bu depo bir market değildir. Bu depo, marketin self kasasında çıkan o kutsal cümlenin resmi savcılığıdır:

> **Beklenmeyen nesne algılandı.**

Nesne sensözü. Nesne poşet. Nesne senin elindeki ekmek. Nesne, bazen de kasanın kendi gölgesidir. Savcılık ayırt etmez. Savcılık tartar.

## Ne işe yarar

Gerçekten çalışır. Gereksizdir. Patates içermez, içerse de dosya düşer.

Program şunları yapar:

1. Ürünün gramajını, barkodunun okunup okunmadığını ve poşet şüphesini alır.
2. Beklenmeyenlik katsayısını hesaplar. Formül ciddidir, sonuç saçmadır.
3. Türkçe iddianame basar.
4. Altına damga, imza, tarih ve isim vurur. Ciddi değildir. Mühür ciddidir.

## Kurulum

Python 3 yeter. Bağımlılık yoktur. Self kasa da böyle başlamıştı, sonra insanlığa düşman oldu.

```bash
python3 savcilik.py --urun "ince belli cay bardagi" --gram 180 --barkod-yok --poset
```

Örnek çıktı iddianame formatındadır. Kasiyer çağırmaz. Kasiyer artık tanıktır.

Gizli zabıt ancak şu bayrakla açılır. Açmazsan dosya kapalı kalır, kuyruk uzar:

```bash
python3 savcilik.py --urun "ekmek" --gram 400 --gizli
```

## Yargı çizelgesi

| Katsayı | Hüküm |
| --- | --- |
| 0 – 25 | Beraat. Nesne bekleniyormuş, sensör yalan söylemiş. |
| 26 – 55 | Para cezası: 1 adet özür ve fişin katlanması. |
| 56 – 80 | Poşet müsadere. İçindekiler tanık sıfatıyla dinlenir. |
| 81 – 100 | Kasa kapanır. Vatandaş yan kasaya sürgün edilir. |
